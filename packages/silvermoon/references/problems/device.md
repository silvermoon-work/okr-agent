# Device preparation

Repair the reported device prerequisite, then reobserve the same target. The
running scoped installation must be discoverable as `silvermoon` on PATH, and
its canonical `skills/silvermoon` must have a personal discovery link. User
config retains `version: 1` and optional canonical `preferredLanguage`;
versionless compatibility is also accepted, but unknown/future fields fail. Do
not silently replace a legacy installation or link. Installation and global
changes require their own authorization. Project/Idea checks have not run; no
later phase may be inferred. Snapshot-only checks omit this boundary.
