# Synchronize the signed draft

The exact current draft has a matching human signoff, but its signed bytes and
decision are not yet present on configured primary. Do not request the next
signoff or execute against new draft standards. Validate the candidate, then use
ordinary authorized Git tools to commit, integrate and synchronize the same
content. Reobserve. Editing signed content makes its signoff stale; do not copy
an old approval to a new revision. Silvermoon never performs these Git writes
for you.
