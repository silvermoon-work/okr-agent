# Project preparation

Repair the reported configuration, layout or Git-root fault. Use v2
`.silvermoon/config.yaml` with `primaryRepository: owner/repository`,
`primaryBranch`, and optional canonical `preferredLanguage`. Do not rewrite
unknown schemas. Only `.silvermoon/i` is the new inventory. Preserve the old
archive, guidance and unrelated files; do not migrate or inject them. Run a
snapshot check after repair. Incomplete consensus is not malformed data.
