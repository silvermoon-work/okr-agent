# Idea 观察

只读取 `.silvermoon/i`；旧 `.silvermoon/ideas` 留档不迁移、不回退使用。
当前阶段和批准向量由事件及准确内容 revision 推导，不接受调用方声明。

## idea-invalid

选择器必须唯一解析到符合协议的 Idea。修复明确的身份、文件或事件错误后复查。
执行规则必须绑定 bootstrap 记录的准确 Check CID；缺失、不可信或不支持的
固定 CID 是执行错误，不得使用最新版替代。

## abandoned

有效事件中的 abandon 会停止推进。只有明确授权的有效 resume 事件才能恢复，
不能从沉默、正文或 Agent 叙述推断恢复。
