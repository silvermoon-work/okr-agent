# Node.js 工具链检查外部验证初版

## Steps

### D-S01: 准备独立消费环境

在仓库外安装准确打包制品，按实施确定的支持矩阵准备真实 Node.js 工具环境；环境准备与 Check 执行分离，不修改共享机器的全局工具选择。

### D-S02: 验证真实工具链要求

从独立环境构建并运行标准 Task
Bundle，验证工具、配对、nvm 管理及 npm/pnpm/nrm 配置要求，保留准确制品身份和执行证据。

### D-S03: 记录交付结论与限制

记录独立消费结果、平台覆盖和未验证范围；若需要 npm 发布，另行取得明确授权后遵循单包 RC 流程，不将本 idea 创建或验收视作发布授权。

## Acceptance criteria

### D-AC01: 仓库外可独立消费

记录证明准确打包制品无需本仓库源码或隐藏依赖，即可构建并通过真实 Engine 执行，输出文档可读取。

### D-AC02: 已声明平台具有真实证据

对声明支持的平台与 nvm 实现保留实际管理、配置覆盖和不满足场景证据；未运行组合明确列为未验证，不以模拟测试代替。

### D-AC03: 交付与授权边界清楚

记录可复用的消费入口、制品身份和限制，检查未修改环境；如未授权发布，明确保持未发布而非宣称 npm 可用。
