# Deployment

## Steps

### D-S01: 同步可消费契约

将最终描述契约及适用标准同步到 primary，固定文档或获准构建制品的准确修订；不执行 npm 发布或 Cloudflare 部署。

### D-S02: 验证独立消费

在明确允许的独立样例中验证描述与检查结果，区分设计推演、静态检查和实际运行证据。真实发布或远端资源操作需要另行授权。

## Acceptance criteria

### D-AC01: 修订可追溯

通过 primary 可达提交和精确引用证明消费者读取的是同一份契约；若交付 CAR，记录对应准确 CID。

### D-AC02: 消费边界可验证

通过独立案例的输入与结果证明声明语义可用；记录验证层级，不以模拟、配置完整或 CLI scaffold 冒充真实部署成功。
