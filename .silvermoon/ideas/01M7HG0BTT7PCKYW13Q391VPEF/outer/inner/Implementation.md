# Implementation

准备阶段的轻量初版；具体字段与组件位置在实施时确定。按用户授权由 subagent 实现，主 Agent 基于校验与审查证据负责 implementation 门限审批。

## Steps

### I-S01: 定义 Spec 与真实样例

结合已确认的 precondition 语义，用真实 Check 完善字段、版本与校验约束。

### I-S02: 实现 React 定义视图

实现可嵌入的脉络与详情组件，支持条件、批量展开及共享和循环引用。

### I-S03: 验证契约与渲染行为

补充针对无效 Spec、引用与交互边界的测试，更新使用文档并运行项目要求的校验。

## Acceptance criteria

### I-AC01: Spec 语义可表达且可校验

真实样例可描述节点契约与展开规则；正反例测试证明结构和引用校验有效，不将文档条件误当可执行证明。

### I-AC02: 组件可嵌入并可靠导航

React 容器样例与交互验证证明详情、条件分流、批量标记、共享引用和循环终止可用。

### I-AC03: 项目校验与文档完整

使用文档说明前置条件的责任边界；项目要求的检查通过且未改变 Check 执行协议。
