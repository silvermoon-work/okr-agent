# Deployment

本文件是准备阶段的外部验证种子，不授权发布；部署阶段按已同步的确切契约验证消费体验，不以实施测试替代独立消费结果。

上游 Space 已发布；本阶段仍须等待本 Idea 实施验收，不以发布事实代替独立消费验证。

## Steps

### D-S01: 准备独立消费环境

在工作区外的隔离临时项目使用两包的本地 tarball 与明确来源的外部 Task
Engine。相关上游依赖以已核实的 0.1.0-canary-261111-2 为基线，验证 Space 支持和 Windows 兼容，不得隐式回退到构建工具自己的 node_modules。新两包可本地打包消费，但不能将其描述为已完成本项目 npm 发布。

### D-S02: 执行独立作者到引擎闭环

按交付文档初始化、外部编辑并一次构建，交由独立 Task
Engine 执行同一真实 check，验证三类结果及打包资源。记录命令、版本、制品身份和实际输出，关闭仅由本次创建的进程，仅清理本次拥有的临时路径；不触碰共享环境、旧历史或发布状态。

## Acceptance criteria

### D-AC01: 独立消费不依赖作者工作区

工作区外消费交付包完成初始化、编辑和构建；安装与调用记录证明使用了声明的依赖，无源工作区隐式解析。明确是否仍有修复未发布的限制，不宣称已完成 npm 发布或 registry 验收。

### D-AC02: 引擎结果与资源证明完整

独立 Engine 实际执行标准制品，观察通过、不通过、执行故障及资源读取；业务 JSON 中的 documentation 路径可结合 Run 的最终 outputCid 读取参考标准文档。证据关联准确制品和依赖版本，确认进程与临时资源已回收，且未执行未经授权的发布行为。
