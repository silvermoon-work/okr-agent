# Deployment

仅规划本地候选试跑，不授权 npm 发布、上传、发布标签或线上部署。

## Steps

### D-S01: 确认试跑环境和候选

选择与 CAR 协议匹配的 Task Engine，记录准确候选 CID、输入项目与调用命令。

### D-S02: 验证真实项目的可用结果

在当前项目或获准本地样例试跑，读取直接 CID 文档及 parent 日志，
不因检查通过声称目标类型检查、构建或发布已经运行。

## Acceptance criteria

### D-AC01: 试跑候选可追溯

真实调用对应准确 CAR/CID 和已接受候选，不使用旧服务协议解释新制品失败。

### D-AC02: 结果可消费且无目标副作用

通过 CLI/内容读取与受控前后对照，证明结果、问题文档和日志可读，
目标内容未被修改，且没有运行目标代码或发布操作。
