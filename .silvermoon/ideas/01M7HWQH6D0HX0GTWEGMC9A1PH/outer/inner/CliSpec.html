ipfsaw CLI Spec

首轮接口候选 v1；主 Agent 受托设计，实际实现与门限证据另行验证。

主实现 @silvermoon-work/ipfsaw；独立仓库的 ipfsaw 仅为薄入口。本文所有命令例子均为预期契约，不是已执行或已发布的证明。

命令树

首轮一项主场景与绑定管理；不增加 daemon、发布或独立 IPFS 配置命令。

共享契约

  • ipfsaw <document> 持续预览
    • renderer 仅分组，无参数显示该组帮助
      • add <schema-uri> <cid>
      • list
      • remove <schema-uri>

共享契约

需求来源：已确认的本地持续预览 / Task Store 复用，加上用户授权主 Agent 完成的资源及接口设计。

包与入口
二进制名为 ipfsaw。Alias 调用主包公开 @silvermoon-work/ipfsaw/cli 的 main(argv): Promise<number>，不改写 argv、不二次启动 npx、不复制业务逻辑。
配置
--config <file> 可用于所有命令；只包含 version:1、renderers 和可选 openBrowser。默认使用平台用户配置目录下 ipfsaw/config.json，Windows 使用 LocalAppData。缺文件等于空绑定，非法文件显式失败。具体值优先级为命令参数、用户配置、产品默认。
IPFS
只在预览场景调用现有 Task 工具链的 Store helper，使用相同配置来源、默认值与 backend 限制。绑定命令不初始化 Store，不添加第二份 IPFS 配置，也不自动使用公网 fallback。
输出流
stdout 只含主要结果；预览时为就绪 URL，管理时为绑定结果。诊断、加载与文档更新消息走 stderr，不默认打印文档正文、能力 token 或堆栈。非 TTY 与 NO_COLOR 禁用装饰，不依赖交互提示。
退出码
0 为帮助、版本或已完成管理操作；1 为输入、配置、内容、运行或清理失败；2 为 CLI 用法错误。预览正常等待，SIGINT 为 130、SIGTERM 为 143；清理故障仍显式报告且不能返回 0。
帮助
所有 callable 节点支持 -h/--help；根无参数和 renderer 分组无参数显示简明帮助并返回 0。--version 为独立根选项。未知命令或选项不静默忽略。
正确性与信任
Schema URI 精确匹配，CID 必须是 bundle 根；不从文档安装代码，不上传或修改源文档，不把 CID 当可信认证。Renderer 不在 Node 中执行。源文档、manifest、bundle 和文件数按 Design 中的明确预算验证。
首轮不支持
不从 stdin 预览；不自动搜索文件；无 marketplace、编辑器、后台 daemon 或 npm / IPFS 发布命令。根预览没有 JSON 输出模式；管理自动化使用 renderer list --json。只有 list 接受该标志。

ipfsaw <document>

S-VIEW；主 Agent 受托设计候选，待实现验证。

读取一份本地文档，按根 $schema 及本次配置快照查准确 renderer CID，启动回环浏览器入口，保存后持续更新。

ipfsaw <document> [--config <file>] [--no-open]
       [--content-gateway <url>] [--content-data-dir <directory>]

共享契约全部适用；此命令是持续运行服务，不是一次性转换。

参数

名称类型 / 输入必需默认用户配置约束
document位置参数，文件路径预览必需无无YAML / YML / JSON；对象根且有字符串 $schema；- 不能冒充监听文件
--config文件路径否共享契约中的用户路径绑定与浏览器偏好非法配置不可被覆盖参数掩盖
--no-open布尔开关否默认自动打开openBrowser显式使用时只输出地址，不启动浏览器
--content-gatewayURL否共享 Store 配置现有 Task 配置原 helper 的同名覆盖语义；不能绕过 backend 验证
--content-data-dir目录否共享 Store 配置现有 Task 配置不创建另一套 ipfsaw 内容配置；Kubo 不混用 local 字段

输出与行为

stdout
HTTP 就绪后仅一行本地 URL；若有本次运行能力标识，放在浏览器 fragment，不当作普通诊断打印。URL 表示服务就绪，不冒充 renderer 已完成绘制。
stderr
加载状态、明确的文件 / 配置 / CID / renderer 错误及更新反馈；语法错误包含位置和原因，不默认泄露正文。
退出码
启动失败 1，用法错误 2；运行中可纠正的文档错误保留服务并显示错误状态，不能把旧视图当作当前有效 revision。中断使用共享信号码。
副作用
仅创建本次 HTTP / watcher / Store 资源，读取既有映射和不可变 bundle。地址固定回环，端口由系统分配。Ctrl+C 等待释放资源；不停止外部 Kubo。
交互
不提示缺失参数；无参数显示帮助。自动打开失败应明确警告并保留可访问 URL，不能谎报浏览器打开成功。文件保存更新不需要重启 CLI；绑定修改需重新启动。

ipfsaw renderer add

S-BIND；主 Agent 受托设计候选。

记录一个明确的 Schema URI / 根 CID 绑定；这是用户选择 renderer 的授权操作，不是自动下载或执行。

ipfsaw renderer add <schema-uri> <cid> [--replace] [--config <file>]

共享契约适用；不接收预览专属 content 选项或 --json。

参数

名称类型必需默认 / 配置约束
schema-uri位置字符串是无非空完整 URI，精确匹配，不模糊补全
cid位置字符串是无合法根 CID，不接受 path 或远端脚本 URL；以规范 CID 表示保存
--replace布尔否false已有不同 CID 时必须显式提供，不能用交互提示代替
--config文件路径否共享配置路径原子写入，保留其他有效设置

输出与行为

stdout
写入后的 Schema / CID 对应关系；相同绑定明确报告未修改。
stderr
配置或覆盖冲突的诊断与 --replace 建议。
退出码
完成或幂等未修改为 0；坏配置 / 冲突 1，参数不完整或非法 2。
副作用
只原子更新所选本地配置；不获取 bundle、不打开浏览器、不创建 IPFS Store。
交互
不要求确认提示，覆盖依赖显式开关；中断清理自己创建的临时文件。

ipfsaw renderer list

S-BIND；主 Agent 受托设计候选。

查看当前配置中的精确绑定，不探测 IPFS 或执行 renderer。

ipfsaw renderer list [--json] [--config <file>]

共享契约适用；无 stdin、浏览器或 Store 副作用。

参数

名称类型必需默认 / 配置约束
--json布尔否falsestdout 输出单个稳定 JSON 对象，不混入人类日志
--config文件路径否共享配置路径缺文件等于空列表，非法文件不等于空列表

输出与行为

stdout
默认显示按 Schema 排序的对应关系；JSON 为 {version:1, renderers:[{schema,cid}]}，不含时序或秘密字段。
stderr
仅读取失败或坏配置诊断。
退出码
成功（包括无绑定）0，读取 / 配置错误 1，用法错误 2。
副作用
无文件写入，不创建 Store。
交互
无提示；支持非 TTY；退出不会留下后台资源。

ipfsaw renderer remove

S-BIND；主 Agent 受托设计候选。

删除所选 Schema 的本地绑定，不删除 bundle、共享内容或其他人的 pin。

ipfsaw renderer remove <schema-uri> [--config <file>]

共享契约适用；没有批量通配删除。

参数

名称类型必需默认 / 配置约束
schema-uri位置字符串是无只删除这个精确键，不把 * 当通配符
--config文件路径否共享配置路径非法文件不重建，其他有效字段保留

输出与行为

stdout
明确报告已移除或未找到、未修改；不假装删除不存在的项。
stderr
配置 / 写入错误。
退出码
完成或幂等未修改 0，配置 / 写入错误 1，用法错误 2。
副作用
最多原子更新一个用户明确选择的配置文件；不访问 Store。
交互
精确删除请求本身表达意图，无额外 TTY 提示。中断清理自己创建的临时文件。
