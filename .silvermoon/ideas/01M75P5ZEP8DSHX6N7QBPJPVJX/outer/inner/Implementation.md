# Preset 标准检查实施初版

## Steps

### I-S01: 盘点首批标准与依赖

构想确认后，盘点选定 preset 的实际要求，区分标准、模板实现与继承复用，形成最小 requirements 和依赖边界。

### I-S02: 验证子检查组合协议

基于真实 Task 调用验证层级结果、准确子输出身份与文档链接，不先建设完整通用政策框架。

### I-S03: 实现首批标准与回归

按已确认范围实现专用 Check 及参考文档，并让选定 preset 与非继承项目共同接受验证。

## Acceptance criteria

### I-AC01: 标准独立于来源

以继承、未继承及等价实现 fixture 证明规则判断当前事实而非模板来源。

### I-AC02: 组合保留真实结论

通过真实 Engine 验证多层结果、子文档解析、故障/取消传播及明确的递归边界。

### I-AC03: 范围与仓库质量一致

实现符合已确认契约，相关测试及仓库检查通过；不将未决讨论偷偷固化成已支持能力。
